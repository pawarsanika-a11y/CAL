# 🧮 Calculator Tracker

A simple web-based calculator enhanced with **labeled calculation history**.
This project was developed as part of the **ACM-W Technical Team Recruitment – Round 2: Blind Feature Implementation Challenge**.

## 🚀 Feature

### Labeled Calculation History

A normal calculator only gives a result, making it difficult to remember why a particular calculation was performed.

Calculator Tracker solves this by allowing users to attach a **label/note** to each calculation.

**Example:**

```text
Label: Monthly Budget
Calculation: 2500 - 800
Result: 1700
```

The calculation can then be viewed in the history for future reference.

## ✨ Key Features

* 🧮 Basic calculator operations
* 📝 Add a label/note to calculations
* 📜 View calculation history
* 🔍 Search previous calculations
* 🗑️ Delete individual history entries
* 🧹 Clear calculation history
* 💾 Persistent history using browser `localStorage`
* 🔄 Restore previous calculations
* 📅 Store calculation date/time
* 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Calculator logic and feature implementation
* **localStorage** – Persistent calculation history

## ▶️ How to Run

No installation or backend server is required.

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, use the **Live Server** extension in VS Code.

## 💡 Problem Solved

Traditional calculators provide results but do not provide context about why a calculation was performed.

This feature converts the calculator into a lightweight **calculation tracking tool**, allowing users to organize and revisit calculations based on their purpose.
